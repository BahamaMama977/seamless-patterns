# seamless-patterns для Codex

Скилл создаёт растровые тайлы для принтов, тканей, обоев и текстур. Он помогает выбрать способ создания рисунка, собирает точное превью 3×3 и проверяет стыки, угловые схождения и ритм повторения.

Стиль, палитра, фон, плотность, размеры объектов и промежутки задаются в запросе. В скилле нет обязательной темы или фиксированных художественных настроек.

## Что понадобится

- Codex с доступным встроенным генератором изображений и просмотром локальных картинок. Наличие генератора зависит от текущей сессии; без него можно проверить готовый тайл.
- Python 3.9+ и Pillow для локальной сборки и проверки. Codex сначала использует готовую среду, включая свой bundled runtime, если он доступен.

Отдельные ключи API и аккаунты сторонних генераторов для этого скилла не нужны. Если подходящей среды Python нет, попроси Codex помочь её настроить.

## Установка

1. Скачай репозиторий через **Code → Download ZIP** и распакуй архив либо клонируй его.
2. Скопируй папку `seamless-patterns` целиком в пользовательскую папку скиллов Codex:

   | Система | Папка установки |
   |---|---|
   | Windows | `%USERPROFILE%\.agents\skills\seamless-patterns` |
   | macOS / Linux | `~/.agents/skills/seamless-patterns` |

   Файл `SKILL.md` должен лежать непосредственно внутри `seamless-patterns`, рядом с папками `scripts`, `references`, `agents` и `licenses`.

3. В чате Codex вызови скилл через `$seamless-patterns`. Если он не появился, перезапусти Codex.

Пользовательская папка `~/.agents/skills` и вызов через `$` описаны в [официальной документации OpenAI](https://learn.chatgpt.com/docs/build-skills). Если у тебя уже есть рабочая копия скилла в другой папке, которую читает Codex, обновляй эту копию: одинаковые имена в нескольких местах могут появиться в списке одновременно.

Для обновления скачай свежую версию и замени установленную папку `seamless-patterns`. Результаты работы сохраняй в папке задачи, отдельно от установленного скилла.

## Как пользоваться

Прикрепи референсы и напиши, какой принт нужен. Укажи тему, стиль, палитру, фон, размеры мотивов, желаемую плотность и допустимость перекрытий. Для печати добавь размер повтора, DPI и формат файла.

### Отдельные объекты с промежутками

```text
$seamless-patterns
Создай квадратный бесшовный принт по приложенным референсам:
небольшие коты в разных позах, тонкий коричневый контур,
кремовый однотонный фон. Размер котов — 8–12% стороны тайла.
Раскладка свободная, без перекрытий, промежутки между силуэтами
не меньше 2% стороны тайла, включая соседей через края и углы.
Подготовь PNG и точное превью 3×3, проверь все стыки и схождения.
```

Для такой композиции Codex генерирует прозрачные мотивы и собирает тайл локально. При требовании промежутков проверяются реальные силуэты после масштабирования и поворота, включая периодические копии через края и углы. Расстояния между центрами сами по себе не обеспечивают нужный зазор.

### Цельный орнамент

```text
$seamless-patterns
Создай квадратный бесшовный орнамент по приложенному референсу:
синие и кремовые цветы, плавные взаимосвязанные линии,
плоские заливки и крупные мотивы. Сохрани цельность рисунка
и ритм референса. Подготовь один тайл, точное превью 3×3
и отчёт. Проверь продолжение контуров на всех краях и в углах;
исправь обнаруженные разрывы и проверь последнюю версию.
```

Для связанных линий и непрерывных фактур Codex работает с целым тайлом. Генератор может потребовать направленных правок. Само слово «бесшовный» в промпте не подтверждает качество стыков.

### Проверка готового файла

```text
$seamless-patterns
Проверь приложенный тайл на бесшовность. Собери точное превью 3×3,
просмотри оба направления стыков, все четыре угловых схождения
и общий ритм. Передай превью и отчёт с описанием найденных дефектов.
```

## Фон, плотность и масштаб

Эти параметры можно сочетать в промпте: например, крупные цветы с редкой раскладкой на зелёном фоне или мелкие рыбы с плотными перекрытиями. Лучше описывать размер объектов отдельно от плотности: «мотивы 3–5 см, между ними 1 см» либо «мотивы 10% стороны тайла, заполнение свободное».

Локальный сборщик поддерживает однотонный и прозрачный фон. Фон с фактурой, горошком или собственным орнаментом тоже должен повторяться без швов; для него нужна отдельная периодическая подложка либо работа с целым тайлом.

## Разрешение и 300 dpi

Для печати укажи и число пикселей, и физический размер повтора. Например, тайл **3600 × 3600 пикселей при 300 dpi** соответствует повтору **30,48 × 30,48 см**. Метаданные DPI не добавляют детализации; увеличение маленького исходника не создаёт новых деталей.

Фактическое разрешение генератора проверяется по файлу. Размер локально собранного тайла задаётся отдельно, а резкость зависит также от исходных мотивов. В запросе можно добавить: «Сохрани 300 dpi, укажи фактические размеры и сообщи, если применялось увеличение». После изменения размера или экспорта конечный файл проверяется заново.

## Что будет в результате

- Один готовый тайл и его фактические размеры.
- `preview-3x3.png`: девять точных копий тайла без дорисовки и сглаживания стыков.
- Вырезки вертикальных и горизонтальных стыков, а также четырёх угловых схождений.
- `inspection.json`: отчёт о точности сборки и результатах визуального просмотра.
- При сборке из мотивов: исходные мотивы, `composition.json` и `replay-config.json` для воспроизведения раскладки.

Успешный запуск скрипта подтверждает точность копий в превью. Статус визуальной проверки заполняется после просмотра: видимых дефектов не обнаружено, найдены дефекты или проверка не завершена. Проверка изображения не заменяет пробную печать на выбранной ткани.
